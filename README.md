# ISO 9001 Rules Check Tools

這是一個用來檢查 PDF 文件，並找出每個段落或小節可能對應哪些 ISO 9001 條文的小工具。

## 目標

- 輸入可選取文字的 PDF
- 自動切出文件中的段落或小節
- 對每個段落或小節列出可能對應的 ISO 9001 條文
- 先做「條文對應建議」，不做符合/不符合判定

## 進度

- 已完成專案骨架與 CLI 入口
- 已建立基本資料模型
